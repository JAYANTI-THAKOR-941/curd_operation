# Server-side CRUD Exercise

Product listing and editing exercise with server-rendered EJS views.

## Project structure

- `index.js`
- `views/products.ejs`
- `views/edit-product.ejs`
- `public/style.css`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/curd_operation.git
cd curd_operation
```

Run `npm install` and inspect the package scripts or launch `node index.js`.
